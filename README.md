# CloudCode AI

CloudCode AI is a cloud-native, AI-powered code review platform.

It analyzes GitHub repositories for:

- Security vulnerabilities
- Code quality issues
- Performance problems
- Hardcoded secrets

The platform combines static analysis tools with AI-powered
explanations and recommendations.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- FastAPI
- Python

### Cloud
- AWS

### AI
- LLM-based code analysis
